Noah sur ordinateur et sur le web, version 0.1.6

Le même style que le téléphone : une barre latérale fine, la discussion au centre, et ce qu'on ouvre (une grille, un PDF, l'écran de l'agent) dans un panneau à droite. L'app de bureau et le site web sont identiques, à la barre de titre près.

Ce qui change par rapport à la 0.1.5

  • Plus de rangée d'onglets au-dessus du panneau : Discussion, Activité, Tâches, Fichiers et Ordinateur sont dans la barre latérale, dans l'ordre choisi sur le téléphone.
  • Un document, une grille ou une image restent petits dans la discussion ; un clic les ouvre dans le panneau de droite, un double-clic en plein écran.
  • Plus aucune fenêtre Windows : une demande d'accord s'affiche en bandeau dans l'app, dessiné par l'app de bureau elle-même.
  • Clic droit sur un fichier : Ouvrir, Ouvrir avec, Afficher dans le dossier, Copier.
  • Réglages en deux colonnes ; la version de l'app et celle du serveur côte à côte.
