Connecter Gmail en un clic

Hermes sait déjà s'authentifier auprès de Google. Aujourd'hui, l'adresse de retour pointe vers localhost, que ton navigateur ne peut pas joindre, d'où le copier-coller d'URL. On remplace seulement ce retour.

  1. Clic

    L'utilisateur touche « Connecter Gmail » dans l'app.

  2. URL Google

    Le control plane demande l'URL de connexion à Hermes et ouvre Google.

  3. Accepter

    L'utilisateur se connecte et accepte les accès demandés.

  4. Retour

    Google renvoie vers /oauth/callback, qui transmet le code au conteneur de l'agent.

  5. Connecté

    Hermes stocke le jeton, l'app affiche « Gmail connecté ✓ ».

Installation en une commande

Le script vérifie Docker, génère les secrets, lance la pile et affiche l'adresse à ouvrir.

Terminal
curl -fsSL https://notre-domaine/install.sh | sh
✓ Docker détecté
✓ Secrets générés dans ~/.agent/.env
✓ docker compose up -d (5 services)
→ Ouvre https://agent.local et colle ta clé API

Feuille de route

  1. Un agent qui parle

    Compose avec Hermes, le control plane et l'app. Un seul agent, outils masqués dans le chat.

  2. Plusieurs machines

    Un conteneur par agent, navigateur visible en direct, approbations.

  3. Proactif

    OAuth Gmail et Agenda, résumé du matin, vérifications périodiques, notifications.

  4. Distribuable

    Script d'installation, PWA mobile soignée, option microVM.

Points de vigilance

Injection de prompt

Un courriel ou une page web peut contenir des instructions. Toute action sortante passe par une approbation.

Port 8642

Jamais exposé à Internet. Seul le control plane y accède, avec API_SERVER_KEY.

Isolation

Les profils Hermes ne cloisonnent pas les fichiers. D'où un conteneur par agent.

Coûts du modèle

Un agent toujours actif consomme en continu. Budget mensuel et plafond par agent.
